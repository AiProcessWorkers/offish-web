# offish-web

**Offish** 웹 확인용 빌드입니다. 바닷속을 헤엄치는 직장인 다이버 도트 게임이에요.

▶ 플레이: https://aiprocessworkers.github.io/offish-web/

- 가로 화면 게임입니다. 휴대폰에서는 가로로 돌려 주세요.
- 화면을 누르고 끌면 그 자리에 조이스틱이 나타납니다. 오른쪽 아래 **살려줘**, **퇴근** 버튼.
- 확인용 빌드라 왼쪽 위에 **처음** 버튼(닉네임 화면으로 돌아가기)이 있습니다.
- 이 저장소에는 빌드 결과만 있습니다. 소스 코드는 비공개 저장소에서 관리합니다.

배포 방법은 소스 저장소의 `docs/BUILD.md` 3.6을 따릅니다 (`tools/build_web.sh` → `tools/publish_web.sh`).
